## About me

I'm a Data Scientist with **6+ years of experience** across speech technology, natural language processing, large language models, and applied machine learning. My work spans research and experimentation through API design and deployment, with a particular interest in making AI work well for Arabic speakers.

- 🗣️ **Speech AI:** speaker verification, audio classification, voice technologies, and TTS
- 🌍 **Arabic AI:** Arabic NLP, speech benchmarks, and language-aware applications
- 🤖 **LLMs & agents:** agentic workflows, tool-using systems, and practical AI automation
- 🚀 **Applied ML:** reproducible experiments, FastAPI services, testing, and deployment
- 🧑‍🏫 **Knowledge sharing:** mentoring, research, and turning complex ideas into usable systems

## Selected work

### [Arabic Speaker Verification Benchmark](https://github.com/Ryuodan/arabic-sv-benchmark)

Companion code and evaluation assets for *Evaluation of Speaker Verification Models in Arabic Datasets*. The benchmark covers six model families—including ECAPA-TDNN, TitaNet, WeSpeaker, pyannote embeddings, and WavLM—across Arabic and English evaluation data.

### [Arabic TTS Studio](https://github.com/Ryuodan/webapp_tts_arabic)

A local Arabic text-to-speech studio built around OmniVoice, with a Saudi-focused fine-tuned checkpoint, voice cloning, model comparison, and LLM-assisted Arabic script composition and text preparation.

### [Arabic NLP Exploration](https://github.com/Ryuodan/Arabic-NLP-Exploration)

A notebook-based walkthrough of techniques for Arabic sentiment analysis.

### [ML Deployment with FastAPI](https://github.com/Ryuodan/deploying-ml-udacity)

An applied machine learning deployment project covering a FastAPI inference service, tests, continuous integration, and model/data versioning practices.
